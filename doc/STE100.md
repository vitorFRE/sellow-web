# ASD-STE100 writing rules for this document set

This document set follows **ASD-STE100** (Simplified Technical English).

ASD-STE100 has two parts:

1. Writing rules
2. A controlled dictionary

This project adds **technical nouns** and **technical verbs**. See [glossary.md](./glossary.md).

---

## Writing rules in use

### Words

- Use approved general words with one meaning.
- Use project technical nouns and technical verbs from the glossary.
- Do not use unnecessary synonyms.
- Do not write noun clusters of more than three words.

### Verbs

- Use these verb forms only:
  - infinitive
  - imperative
  - simple present
  - simple past
  - simple future
  - past participle as an adjective
- Do not use complex verb constructions.
- Use the `-ing` form only as a technical noun or as a modifier in a technical noun.

### Sentences

- Use the **active voice**.
- Write one instruction in each procedural sentence.
- Limit procedural sentences to **20 words**.
- Limit descriptive sentences to **25 words**.
- Do not omit the subject, the verb, or the article.

### Paragraphs

- Write one topic in each paragraph.
- Do not write more than six sentences in one paragraph.
- Use vertical lists for complex data.

### Procedures

- Start each step with a command verb when possible.
- Give one action per step.
- State conditions before the action when a condition applies.

## Document types in this set

| Type | Purpose | Word limit |
|------|---------|------------|
| Description | Explain structure and behavior | 25 words per sentence |
| Procedure | Tell the reader what to do | 20 words per sentence |
| Reference | List routes, endpoints, and permissions | Short labels and lists |
